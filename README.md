# Invisible Cloak using OpenCV

A fun computer vision project inspired by Harry Potter's invisibility cloak using Python and OpenCV.

The program detects a blue-colored cloth and replaces it with the previously captured background, creating an invisible effect in real time.

---

## Features

- Real-time invisibility cloak effect
- Uses webcam input
- Color detection using HSV
- Background replacement using OpenCV
- Noise reduction using morphology operations

---

## Technologies Used

- Python
- OpenCV
- NumPy
